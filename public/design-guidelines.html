Design System

사내 HTML 산출물의 시각 통일을 위한 디자인 가이드입니다.
웹 대시보드(타입 A)와 1920×1080 보고문서(타입 B) 두 가지 타입을 지원합니다.

용도별 타입 선택

타입용도파일 형태결정 기준
타입 A 웹사이트 빌드, 대시보드, 내부 툴 HTML (반응형) 화면에서 스크롤하며 보는 산출물
타입 B 보고문서, 임원 보고, PDF 출력 HTML 1920×1080 고정 한 페이지 출력·인쇄하는 산출물

공통 원칙

폰트: Pretendard 기본. 굵기는 Regular(400) · SemiBold(600) · Bold(700) 세 가지만 사용.
텍스트 컬러: Gray 500(#A0A0A0) 이상 또는 배경 대비 3:1 이상만 허용.
컬러 원칙: 키 컬러와 상태 컬러는 의미 단위로만 사용. 장식 목적 금지.

Basic Logo(기본형)와 Horizontal Logo(가로형) 두 가지 레이아웃, 각각 Box ver / Lined ver을 지원합니다.
