CP DESIGN SYSTEM

디자인 가이드라인

기본적으로 Pretendard 서체를 사용합니다. 굵기는 Regular, SemiBold, Bold 세 가지 타입만 사용하기를 권장합니다.
상황에 따라 LINE SEED SANS 서체를 사용할 수 있습니다.
가독성 기준에 따라 Gray 600 이상의 컬러나 대비가 3:1이 확보되는 컬러만 사용 가능합니다.

프로젝트 개요

디자인 철학
  • 데이터 우선 — 복잡한 프로젝트 정보를 명확하게 전달
  • 빠른 탐색 — 필터와 정렬로 원하는 정보에 즉시 접근
  • 시각적 피드백 — 호버, 전환 효과로 인터랙션 명확화
  • 실용적 미니멀 — 꾸밈없이 깔끔하지만 데이터는 풍부하게

사용 원칙

서체
Pretendard를 기본으로 사용. 굵기는 Regular / SemiBold / Bold 세 가지만 권장. 필요 시 LINE SEED SANS 병행 가능.

여백
컴포넌트 간 최소 여백 8px 단위 사용 권장. 섹션 간격은 24px / 32px 기준.

SETUP GUIDE

설치 및 실행

CP Design Insights를 로컬에서 실행하고 Vercel에 배포하는 방법을 안내합니다.

1. 의존성 설치

cd cp-design-insights
npm install

2. Firebase 프로젝트 설정

  1. Firebase Console에서 새 프로젝트 생성
  2. Firestore Database 활성화 (테스트 모드로 시작)
  3. 프로젝트 설정 → 웹 앱 추가
  4. Firebase 구성 정보 복사

3. 환경 변수 설정

cp .env.example .env.local

.env.local 파일에 Firebase 구성 정보 입력:

NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project_id.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project_id.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
보안 주의 실제 값은 절대 Git에 커밋하지 마세요. .env.local은 .gitignore에 포함되어 있습니다.

4. 개발 서버 실행

npm run dev

브라우저에서 http://localhost:3000 접속

5. Vercel 배포

  1. Vercel 계정에 로그인
  2. GitHub 저장소 연결
  3. 환경 변수 설정 (Firebase 구성)
  4. 자동 배포 완료
현재 프로덕션 URL https://cp-design-insights.vercel.app/
AUTHENTICATION

관리자 인증

Firebase Authentication 없이 간단한 패스워드 방식으로 관리자 기능을 보호합니다.

로그인 방법

  1. 메인 페이지 접속
  2. 우측 상단의 Log in 버튼 클릭
  3. 비밀번호 입력: cpdesign
  4. "확인" 버튼 클릭

인증 후 사용 가능한 기능

  • Admin 버튼 표시
  • 프로젝트 추가 / 수정 / 삭제 가능
  • 로그아웃 기능

패스워드 변경

lib/auth.ts 파일에서 수정:

const ADMIN_PASSWORD = 'cpdesign'; // 원하는 패스워드로 변경

보안 참고사항

현재 인증 방식의 특성
  • 인증 정보는 세션 스토리지에 저장됩니다
  • 브라우저 탭을 닫으면 자동으로 로그아웃됩니다
  • 프로덕션 환경에서는 더 강력한 인증 시스템 사용을 권장합니다
