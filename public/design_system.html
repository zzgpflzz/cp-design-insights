📋 프로젝트 개요

디자인 파트의 월간 작업물을 보고하고 아카이빙하는 웹 애플리케이션입니다. 각 프로젝트를 월별로 정리하고, 디자이너별로 구분하며, 상태와 카테고리를 관리할 수 있습니다.

디자인 철학
  • 데이터 우선 - 복잡한 프로젝트 정보를 명확하게 전달
  • 빠른 탐색 - 필터와 정렬로 원하는 정보에 즉시 접근
  • 시각적 피드백 - 호버, 전환 효과로 인터랙션 명확화
  • 실용적 미니멀 - 꾸밈없이 깔끔하지만 데이터는 풍부하게

주요 기능

월별 아카이빙

매달 진행한 작업물을 월별로 분류하여 관리

디자이너 구분

장혜리, 김아영 디자이너별 작업물 표시

인사이트 대시보드

동적 월별 인사이트 및 전문가 리뷰

왜 Pretendard Variable인가?
  • 한글 최적화된 깔끔한 디자인
  • 다양한 font-weight 지원 (가변 폰트)
  • 숫자와 영문의 균형잡힌 조화
  • CDN으로 빠른 로딩

* 폴백 폰트는 Pretendard 로드 실패 시 시스템 기본 폰트로 대체

🎨 UI/UX 디자인

디자인 원칙

1. 스캔 가능한 레이아웃

그리드 기반 카드 레이아웃으로 프로젝트를 빠르게 스캔할 수 있습니다. 3열 그리드로 한눈에 정보 파악이 가능합니다.

2. 즉각적 필터링

월별, 카테고리, 상태별 필터를 한 번의 클릭으로 적용. 필터바는 항상 상단에 고정되어 접근성을 높였습니다.

3. 명확한 시각적 상태

배지 색상만으로 프로젝트 상태를 즉시 파악 가능. Release는 초록색, In Progress는 주황색으로 직관적으로 구분됩니다.

접근성 (Accessibility)

현재 적용된 접근성
  • 명확한 색상 대비 - #313131 텍스트 + #FAFAFA 배경
  • 호버 피드백 - 카드 hover 시 translateY + 그림자 강화
  • 터치 친화적 - 버튼 최소 44px 높이, 넉넉한 클릭 영역
  • 상태 시각화 - 배지 색상으로 Release/In Progress 구분
  • 빠른 로딩 - 가벼운 애니메이션으로 성능 유지

⚙️ 설치 및 실행

1. 프로젝트 클론 및 의존성 설치

cd cp-design-insights
npm install

2. Firebase 프로젝트 설정

  1. Firebase Console에서 새 프로젝트 생성
  2. Firestore Database 활성화 (테스트 모드로 시작)
  3. 프로젝트 설정에서 웹 앱 추가
  4. Firebase 구성 정보 복사

3. 환경 변수 설정

cp .env.example .env.local

.env.local 파일을 열어 Firebase 구성 정보 입력:

NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project_id.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project_id.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
보안 주의

실제 값은 절대 Git에 커밋하지 마세요. .env.local은 .gitignore에 포함되어 있습니다.

4. 개발 서버 실행

npm run dev

브라우저에서 http://localhost:3000을 열어 확인합니다.

5. 배포

Vercel을 통한 배포:

  1. Vercel 계정에 로그인
  2. GitHub 저장소 연결
  3. 환경 변수 설정 (Firebase 구성)
  4. 자동 배포 완료
현재 프로덕션 URL

https://cp-design-insights.vercel.app/

🔐 관리자 인증

Firebase Authentication 없이 간단한 패스워드 방식으로 관리자 기능을 보호합니다.

로그인 방법

  1. 프론트 페이지(http://localhost:3000) 접속
  2. 우측 상단의 Log in 버튼 클릭
  3. 비밀번호 입력: cpdesign
  4. "확인" 버튼 클릭

인증 후 사용 가능한 기능

  • Admin 버튼 표시
  • 프로젝트 추가/수정/삭제 가능
  • 로그아웃 기능

패스워드 변경

패스워드를 변경하려면 lib/auth.ts 파일을 수정하세요:

const ADMIN_PASSWORD = 'cpdesign'; // 원하는 패스워드로 변경
보안 참고사항
  • 현재 인증 정보는 세션 스토리지에 저장됩니다
  • 브라우저 탭을 닫으면 자동으로 로그아웃됩니다
  • 프로덕션 환경에서는 더 강력한 인증 시스템 사용을 권장합니다
